# Pandas Data Cleaning Project

This project demonstrates how to clean and analyze a messy dataset using Python Pandas.

## Tasks Performed

- Loaded CSV dataset using Pandas
- Checked missing values
- Handled missing values
- Cleaned date column
- Removed incorrect/outlier duration values
- Created Pulse Difference column
- Created Calories per Minute column
- Filtered high-calorie workouts
- Exported the cleaned dataset to CSV

## Technologies Used

- Python
- Pandas
- Jupyter Notebook

## Dataset Columns

- Duration
- Date
- Pulse
- Maxpulse
- Calories
- Pulse_Difference
- Calories_per_Minute

## Files

- `data_cleaning.ipynb` - Complete Python/Pandas code
- `cleaned_data.csv` - Cleaned dataset
